# GIT

    ### COMANDO BÁSICOS

    Autenticar via computador local no GitHub: 
    ```
    gh auth login
    ```
    Clona Repositório No Github:
    ```
    gh repo clone nome-do-repositorio
    ```
    
    Abrir VS Code:
    ```
    code .


    ### Salvar no GITHUB 


    prepara arquivos para salvar: 
    ```
    git add .
    ```

    Comando para versionar (salvar): 
    ```
    git commit -m "mensagem"

    
    Baixar atualizações do repositório:
    ```
    git pull
    ```


    Enviar para o Github:
    ```
    git push
